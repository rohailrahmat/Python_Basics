## 💡 Overview

This repository contains essential Python concepts with hands-on examples and project-based practice. It aims to help you:

- Understand Python syntax and basic data types  
- Learn control flow and looping mechanisms  
- Write and use functions effectively  
- Understand Python's **LEGB** variable scope model  
- Practice your skills through challenges  
- Build a simple game using everything learned  

---

## 🗂️ Repository Structure

The project is organized into topic-based directories:

| Directory | Description | Key Topics Covered |
|----------|-------------|--------------------|
| **Basics** | Core Python syntax and datatypes | Variables, operators, input/output, type conversion |
| **Basics_Practice** | Short exercises for beginners | Arithmetic, string manipulation |
| **LOOOPs** | Looping concepts with examples | `for`, `while`, `range()`, `break`, `continue` |
| **Funtions** | Function creation and usage | Function definitions, arguments, returns, lambdas |
| **SCOPES** | Understanding Python’s scope system | Local, Enclosing, Global, Built-in (LEGB) |
| **Pratice_Q&A** | More advanced challenges | Logic puzzles, list & dict problems |
| **Python_game** | A small project combining all concepts | Game loop, conditionals, modular code |
